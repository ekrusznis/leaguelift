# Severity guide

- **P0 — Launch blocker:** crash, data loss/cross-org exposure, unauthorized financial/
  admin action, checkout impossible, onboarding bypass, sign-in impossible for core role.
- **P1 — Critical workflow:** major feature unusable, incorrect role access, payment/
  eligibility/messaging safety flow broken, severe mobile layout blocking interaction.
- **P2 — Important:** partial workflow defect, confusing permission UX, bad empty/error
  state, significant clipping/scrolling issue with workaround.
- **P3 — Polish:** copy, spacing, minor visual inconsistency, non-blocking affordance issue.
